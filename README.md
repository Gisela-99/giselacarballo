# Portafolio — Gisela Carballo

Portafolio personal donde muestro mi trabajo como desarrolladora Frontend, combinando código funcional con una mirada visual influenciada por mi formación en Historia del Arte.

🔗 **Demo en vivo:** [giselacarballo.vercel.app](https://giselacarballo.vercel.app)

## ✨ Sobre este proyecto

Desarrollé este portafolio desde cero para presentar mi perfil, mi trayectoria y una selección de proyectos reales en los que he trabajado como desarrolladora Frontend / UI.

## 🛠️ Stack técnico

- **React** + **TypeScript**
- **CSS Modules** para estilos encapsulados por componente
- **react-scroll** para navegación con scroll suave
- Diseño **responsive**, incluyendo menú hamburguesa para móvil

## 📂 Estructura y componentes destacados

- `Navbar` — navegación fija con scroll suave y menú hamburguesa responsive
- `Hero` — sección de presentación principal
- Sección **Proyectos**: Secret Barcelona, Erova y Planeo
- Sección **Trayectoria**: formación académica y cursos complementarios

## 🚀 Cómo correrlo en local

```bash
git clone https://github.com/Gisela-99/[nombre-del-repo].git
cd [nombre-del-repo]
npm install
npm run dev
```
